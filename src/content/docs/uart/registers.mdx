The instance base used here is **UART3: `0x30002000`**. Entries show the console-related TX/RX fields, baud controls, interrupt registers and FIFO interface. Other registers and omitted fields are outside these entries' coverage.

SDK reset values describe the cited register definition. Runtime console values are discussed in the [functional description](/uart/overview/) and are not substituted for reset values.
