## Forwarded sources

SDH's MCU forwarding index is **17**, while the D0 PLIC route observed in the board diagnostic is **81** (`WL_ALL`). A child index and a parent source ID belong to different controller domains; do not derive one by adding an offset to the other.

See the [numbering-domain table](/interrupts/overview/#numbering-domains) and [SDH forwarding path](/interrupts/m0ic/#sdh-delivery-path) before using an ID in a driver or device tree.

The table identifies controller inputs. Driver availability and the observed delivery path are separate properties.
