GLB is the MCU-side global control block at `0x20000000`. This page covers the MCU clock-divider fields and SDH clock controls used by the documented board path.

## MCU clocks

The MCU root comes from the [HBN / PDS selectors](/clocks/hbn-pds/). `SYS_CFG0` holds the MCU core/high-speed divider and peripheral-bus divider. The bus rate follows the core path through the bus divisor.

Changing the divider value is not the complete transition protocol. The bus-divider update sequence also requests application of the setting. See [initialization and reset](/clocks/sequencing/).

## SDH has two gates

The SDH module clock is selected and divided in `SDH_CFG0`. Its bus-interface clock is enabled separately in `CGEN_CFG2`. The host controller then uses its own clock-control register at `0x2006002c` to enable and divide the card clock.

```text
PLL branch → SDH_CFG0 selector/divider/module gate → SDH internal clock
GLB bus    → CGEN_CFG2 SDH bus gate               → register interface
SDH internal clock → host clock divider/output enable → card CLK pad
```

The SDH interrupt path is described under [MCU interrupt forwarding](/interrupts/m0ic/#sdh-delivery-path).

## Recorded SDH parent rates

On the M1s Dock on 2026-10-23, the XTAL marker at `0x2000f10c` read
`0xffff5804`, identifying a 40 MHz reference. Decoding the programmed PLL
settings gave a CPU PLL output of 380 MHz and Wi-Fi PLL VCO of 960 MHz.
The SDH selector therefore chose between:

| `SDH_CFG0` selector | Parent branch | Rate from the recorded PLL settings |
| --- | --- | --- |
| 0 | Wi-Fi PLL VCO / 10 | 96 MHz |
| 1 | CPU PLL / 4 | 95 MHz |

The CPU PLL CFG1 at `0x200087d4` read `0x01100418` and SDMIN at
`0x200087e8` read `0x00013000`. Wi-Fi PLL CFG1 at `0x20000814` read
`0x01110216` and SDMIN at `0x20000828` read `0x91800000`.
These rates describe the programmed state in that session. A fixed
100 MHz assumption for selector 1 would misreport that state. D0's selected
execution path was separately observed at about 320 MHz; it should not be
inferred from the CPU PLL output alone.

Both SDH parents completed CMD8 interrupt tests with module divisors
1, 2, 4, 8 and 1. Native M0 USB continued to respond during each parent
selection. Linux subsequently passed
[SDMA write/readback and restoration](/storage/sd-card/#native-linux-pio-and-sdma)
with both parents. The tests changed SDH controls without retuning the
shared root PLLs; the checked shared PLL and USB register words matched
their saved values afterward.

The native Linux tests used a one-bit card bus. A requested 4 MHz ceiling
resulted in a software-reported card clock of 3 MHz from the 96 MHz module
input, or 2,968,750 Hz from 95 MHz. The host divider selected /32. These are
register-derived rates, not clock-pad waveform measurements.
